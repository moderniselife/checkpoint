# Checkpoint guides

Human-readable docs for everything Checkpoint does: what each feature is, how to use it,
when it helps, and why it works that way. Nothing here is auto-generated — if a guide
disagrees with the app, the app wins; please file an issue.

## Start here

- [Getting started](getting-started.md) — install, connect an AI provider and your tracker, run your first plan.
