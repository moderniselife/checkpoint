How it works

Stop opening ten tabs.

Everything you need to test a ticket lives in one place — researched for you, organised for you, and ready to tick off.

1

Paste a ticket

A key like PROJ-123 or a Jira / Linear link. Choose Dev or QA mode.

2

AI does the research

It reads the ticket, every comment (later ones win), epic children, parent, linked issues and specs — in parallel — and you watch it happen live.

3

Test with a checklist

Numbered steps, one expected result each, acceptance criteria you can tick as met, and every source it read — saved and organised.

Features

Everything a tester actually needs.

Built for the way you verify work — not another dashboard to maintain.

Deep, focused research

Follows comments, epic children, parent, linked issues and Confluence pages or Linear docs — only as far as they change what needs testing.

Tickable plans

Before-you-start setup, numbered steps with one observable expected result, edge cases, open questions. Grouped per ticket for epics.

Acceptance criteria tracking

Tick criteria as met, see which ones no task covers, and track two metrics: tested and AC met.

Every detail, one panel

Description, inline images, attachments, epic children, comments, work log, history and custom fields — in floating glass tabs.

Folders, search, dashboard

Colour-coded folders, smart folders, sidebar search and filters, pins, archive, tags, due dates, batch sprint import, regression suites — and a dashboard for the week.

Live progress

Streamed thinking, per-ticket fetch status, an elapsed timer and a real progress bar — even on huge epics.

Research log

Go back to every lookup and thought behind a plan, with timestamps and duration.

End-to-end scenarios

Optional: realistic user journeys through neighbouring features, built from related tickets — or your codebase, read-only.

Export & share

Save any plan as Markdown or a beautiful self-contained HTML page — light/dark, printable, tickable in the browser. Perfect for sign-offs and Jira comments.

Jira & Linear, any AI

Same features for both trackers — paste a link and Checkpoint picks the right one. Plans by Claude, GPT, Gemini, Grok, OpenRouter or a local model.

Use cases

One app for QA testers, developers and team leads.

Checkpoint is an AI test plan generator for Jira and Linear: it writes test cases from your tickets with Claude, GPT, Gemini, Grok or a local model, so you can spend your time testing, not reading.

Generate test cases from Jira tickets

Paste a Jira issue key or link and get step-by-step manual test cases with a single expected result each — including the edge cases and negative paths people forget.

Turn acceptance criteria into a checklist

Acceptance criteria are quoted from the ticket (or derived when missing), mapped to the test cases that cover them, and tracked as met or not met.

Epic & sprint regression testing

Analyze an epic and every active child is covered, grouped per ticket — ready for a release regression pass.

UAT on the hosted app

QA mode writes black-box, UI-only test plans for staging or production — starting with a check that the fix is actually deployed.

Developer self-testing

Dev mode adds branches, APIs, logs and tests, so you can verify your own change before handing it to QA.

Watch it work

Big epic? You'll see every step.

Checkpoint streams the model's reasoning as it happens, fetches tickets in parallel, and shows exactly where it's up to — then keeps the whole log with your plan.

  • Parallel fetches. All of an epic's children load at once, each flipping to ✓ as it returns.
  • Live thinking. Expand any thought to see why it looked where it did.
  • Honest progress. A timer and a bar that fills while reading and writing — not a spinner that lies.

Privacy & safety

Your tickets stay yours.

Checkpoint runs on your Mac and talks directly to Atlassian, Linear and the AI provider you choose — no Checkpoint servers in between. Run a local model and your tickets never leave your network.

Read-only by design

Jira: only read tools are exposed. Linear: its read-only endpoint and scope, enforced by Linear.

Keys in your Keychain

Your AI provider keys and tracker tokens never leave the macOS Keychain.

Sign in with OAuth

Standard Atlassian and Linear sign-in with PKCE — no admin allowlisting needed.

Sandboxed & local

A sandboxed native app. Plans are stored locally on your Mac.

Get started

Up and running in two minutes.

Download

Grab the latest DMG and drag Checkpoint to Applications. Requires macOS 26.

Pick your AI

Choose Claude, OpenAI, Gemini, Grok, OpenRouter or a local model in Settings (⌘,), add a key, and hit Fetch models.

Connect your tracker

Sign in with Atlassian and/or Linear, hit Test connection, then paste your first ticket.

FAQ

Questions, answered.

How do I generate test cases from a Jira ticket?

Install Checkpoint, choose an AI provider, sign in with Atlassian, then paste the ticket key (for example PROJ-123) or its link. Checkpoint reads the ticket, its comments, linked issues, epic children and Confluence specs, and writes a numbered test plan with expected results in about a minute.

Does Checkpoint work with Linear?

Yes. Sign in with Linear or use a Linear API key. Linear issues get the same test plans, Dev and QA modes, ticket panel, folders and acceptance-criteria tracking as Jira.

Can it turn acceptance criteria into test cases?

Yes. Explicit acceptance criteria are quoted from the ticket, every criterion is mapped to the test cases that cover it, and criteria with no covering test are flagged so nothing slips through. You can tick each criterion as met.

Which AI model does Checkpoint use?

Whichever you like: Anthropic Claude, OpenAI, Google Gemini, xAI Grok, anything on OpenRouter, or a local model. Bring your own key, pick the model from a live list, and set how much effort it spends — lower for quick plans, higher for large epics. Claude gets extras like adaptive thinking and schema-enforced plans.

How is this different from a test case management tool?

Test management tools store test cases you write by hand. Checkpoint writes the test plan for you from the ticket itself, keeps it next to the full ticket details, and tracks what you've tested — no spreadsheet or separate tool to maintain.

Does it work with OpenAI, Gemini or Grok?

Yes. Checkpoint supports OpenAI, Google Gemini, xAI Grok and OpenRouter alongside Anthropic Claude. Paste your API key, fetch the model list, and pick any model that supports tool calling.

Can I use a local LLM like Ollama or LM Studio?

Yes. Point Checkpoint at any OpenAI-compatible server (Ollama, LM Studio, vLLM, llama.cpp) or Anthropic-compatible endpoint (such as LiteLLM) on your machine or network. No API key needed, and ticket content stays local. Use a model with tool calling and a large context window for big epics.

What are test scenarios?

An optional extra: besides the step-by-step test cases, Checkpoint can write 3–6 end-to-end user journeys that exercise the change in context — through the screens and features around it — with a role, goal, steps and end result. Build them from related tickets alone, or also let Checkpoint read your codebase (read-only, only the folder you choose) for journeys that match how the product really works.

Can I build Checkpoint from source?

Yes. Clone the GitHub repository and run ./build.sh — it checks for Xcode 26 and XcodeGen and produces a universal Checkpoint.app in the dist folder. Add --install to copy it to Applications.

Can I share or export a test plan?

Yes. Copy a plan as Markdown for Jira comments and pull requests, or save it as a self-contained HTML page styled like the app — light and dark mode, print-friendly, with checkboxes anyone can tick in their browser.

Is Checkpoint free?

Yes — it's free and open source under the MIT license. You bring your own AI provider key and pay that provider directly for what your plans use — or run a local model for free.

Can it change my tickets?

No. Checkpoint only ever reads. For Jira it exposes read tools only; for Linear it uses Linear's read-only MCP endpoint with a read-only scope, so Linear itself blocks writes.

Does my data go through your servers?

There are no Checkpoint servers. The app talks directly to your tracker's MCP server and to Anthropic's API. Plans are saved locally on your Mac.

Which Macs does it run on?

Any Mac on macOS 26 or later — it's a universal app for Apple Silicon and Intel.

My org restricts Atlassian API tokens. Will it work?

Use Sign in with Atlassian. It uses OAuth with a local redirect that Atlassian pre-approves for every org, so no admin change is usually needed.

macOS says the app can't be opened.

If a release isn't notarized yet, right-click Checkpoint in Applications and choose Open the first time, or run xattr -dr com.apple.quarantine /Applications/Checkpoint.app.
